# Status & Validation Plan: AURA-MOM PRO

## Validation Plan

| Stage | Goal |
| :--- | :--- |
| **Stage 0 — Bench** | Verify power, noise, channel crosstalk, ADC saturation, BLE, battery and sensor repeatability. |
| **Stage 1 — Signal injection** | Inject known maternal/fetal ECG and EHG waveforms into the acquisition chain; calculate SNR, timing error and QRS sensitivity. |
| **Stage 2 — Phantom** | Use an electrical/acoustic abdominal phantom to demonstrate spatial separation and PVDF acquisition without involving pregnant participants. |
| **Stage 3 — Public datasets** | Benchmark fECG and EHG algorithms on public PhysioNet data; report sensitivity, PPV, FHR error and EHG classification metrics. |
| **Stage 4 — Supervised feasibility** | Only with appropriate clinical/ethics oversight, compare prototype outputs against accepted clinical reference measurements. |
