Biomedical Engineering Challenge

Extracting a 20 µV Whisper Beside a 1,000 µV Jet Engine

Dual-Input Differential Biopotential Topology

Abdominal electrodes capture a composite mixture where maternal cardiac electrical vectors dominate the fetal waveform by up to 20:1 in amplitude.

Primary Lead: $d[n]$ (Abdominal Lower)

d[n] = s_fetal[n] + s_maternal[n] + v_emg[n] + v_noise[n]

Contains the tiny 20–50 µV fetal QRS submerged beneath the dominant maternal cardiac waveform and muscular contraction artifacts.

Reference Lead: $x[n]$ (Maternal Axis)

x[n] ≈ s_maternal[n] + v_noise[n]

Acquires the maternal cardiac vector with minimal fetal contamination, providing the pure reference signal for adaptive cancellation.

AFE Solution: TI ADS1298 24-bit Delta-Sigma ADC provides 115 dB CMRR and built-in Right Leg Drive (RLD) to suppress 50 Hz powerline hum and common-mode bodily interference.

Adaptive Cancellation Equation

e[n] = d[n] - w[n]^T x[n],    w[n+1] = w[n] + (μ / (||x[n]||² + ε)) · e[n] · x[n]

Order $M = 32$, Step size $\mu = 0.05$, $\varepsilon = 10^{-8}$. Error residual $e[n]$ directly preserves isolated fetal QRS complexes while maternal energy is cleanly subtracted.
